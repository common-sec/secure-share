Encrypted files

Encrypt files with a password, in your browser, into one file that only the password opens. Nothing is uploaded.

Encrypt files with a password, keep them safe, open them on any system

Add one or more files, or a whole folder, choose a password, and download a single encrypted file. Keep it in your cloud storage, on a USB stick or in a backup: without the password, nobody can read it. To open it, add it here, type the password and download what’s inside, or open it with GnuPG on any computer, as explained below.

  • Nothing leaves your device. The files are encrypted in your browser, nothing is uploaded or stored, and once the page has loaded it works offline.
  • Opens on any system. The encrypted file is OpenPGP (AES-256), the standard format GnuPG uses, so it also opens without this site, on Windows, macOS, Linux and Android.
  • Folders and several files are packaged as a ZIP inside the encrypted file. When it’s decrypted, your computer opens the ZIP as usual.
  • Up to 2 GB in all on a computer. Phones have less memory: keep to a few hundred MB there.
  • Keep the password safe. If it’s lost, the file can’t be opened, by anyone, us included.

Open the file without this site

The encrypted file (.gpg) opens with free tools, offline, on every system. Each one asks for the password, then saves what’s inside.

  • Windows: Gpg4win includes Kleopatra. Open Kleopatra, choose Decrypt/Verify, pick the file and type the password.
  • macOS: with GPG Suite installed, right-click the file in Finder and choose Services › OpenPGP: Decrypt File.
  • Linux, or a terminal anywhere: GnuPG, often already installed: gpg --output report.pdf --decrypt report.pdf.gpg
  • Android: OpenKeychain can decrypt it too.

The other way works as well: a file encrypted with a password by GnuPG (gpg --symmetric report.pdf), Kleopatra or GPG Suite opens here. Files encrypted for a key rather than a password aren’t supported yet.

Sending files to someone

To give files to someone else, use Secure Share (once, to one person) or Secure Chat (several people, or back and forth). The files go straight from your browser to theirs, encrypted end to end, and no copy is kept anywhere.

Avoid sending an encrypted file by email or in a chat app. Copies stay on servers and devices you don’t control, and anyone who keeps one can try to open it later: by guessing the password, or with a weakness found in the future. If the encrypted file itself has to travel, send it with Secure Share, and the password another way. More in the FAQ.
