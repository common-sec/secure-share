Secure Chat

Group chat and file sharing, browser to browser, end-to-end encrypted. No account, no server storage.

Encrypted group chat without an account

Create a private room, share its link and passphrase, and approve each person who joins. Messages and files go directly between browsers, signed and encrypted end to end. When the host closes the room, it’s gone.

  • You decide who’s in. The host approves every member and can compare a safety code with them.
  • Up to eight people, with files of any type.
  • Nothing is stored on a server, and there’s no history once the room closes.
